# WarmUpWise

Warm-up set calculator: build your barbell ramp with exact set weights, reps, rest times and per-side plates. Free.

## Features
- Three ramp schemes: standard 5-set, quick 3-set, and heavy-day 6-set
- Per-side plate breakdown with greedy plate inventory for kg and lb
- Rest-time guidance per set plus dropped redundant steps
